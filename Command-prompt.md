# command prompt shortcuts.
- to boot into command prompt
  1. on the login screen hold shift and click restart
  2. after it restarts select troubleshoot, then advanced options, then command prompt
 
# storage
- to get into the disk partition the command is diskpart
  - to find the various disks you will use command list disk
  - to select a disk use the command select disk #
  - use clean to delete everything but it is recoverable with hardware
  - use clean all to do a through clean that writes zeroes to every sector and it is not recoverable
